------------------------------------------------------------------
一、相对 FIX30 基线的改动
------------------------------------------------------------------
1. 方向残差门强度【运行时可调】+【运动自适应】
   上位机诊断窗滑块 -> "T DIR <0..100>"
   默认 90%（静止上限）
   运动自适应：角速度 10 -> 120 deg/s 之间，强度从用户设定线性降到下限 20%
               下降时间常数 0.03s（快），恢复 0.30s（慢）
   强度同时作用在门限与 e：
       门限 = 3 + (1 - s_eff) * 17  度
       e    = 1 + 3 * s_eff
       -> 静止 0.90：门限 4.7 度，e=3.70（进 hard_event，抗磁全开）
       -> 剧烈 0.20：门限 16.6 度，e=1.60（只软降权，修正照跑）
   运行时可调参数（T DIR）：0 = 等效关闭
2. 硬事件回滚【已恢复】
   进入 hard_event 与恢复时，把 yaw_corr / mag_datum_offset 退回 safe 快照，
   撤销"检测到干扰之前那段可能已被污染"的修正。
   副作用：输出航向会瞬时跳回旧值，快照越旧跳越大。
3. 大修正路径"先冻结再步进"关闭：MAG_YAW_HOLD_S = 0

------------------------------------------------------------------
二、门控清单（全部生效）
------------------------------------------------------------------
物理门（合成 e = max(...)，e<=1 视为干净）：
  门1 磁场大小   |B| 偏离 > 15% 或 9sigma
  门2 磁倾角     dip 偏离 > 11 度 或 9sigma
  门3 单拍阶跃   |w_now - w_lp| > max(0.04, 9.5sigma) + 0.10*omega
  门4 慢漂移     仅仰角，0.5s 窗口，连续 2 个坏窗口才触发
  门5 双磁梯度   两颗磁力计空间不一致（阈值在线学习）
  门6 整手一致性 与本手其它链路中值比较（需 >=4 个对等链路）
硬覆盖：水平分量过低（< 0.10*ref_norm）、方向残差 dir_lock（单拍 > 门限即锁 0.5s）
速率门：角速度上限 540 deg/s
事件机：e>=3 锁 hard_event + 回滚；e>=2.5 权重归零；1<e<2.5 软降权；
        恢复需 e<=1 持续 0.2s；另有统一恢复与 Final guard

------------------------------------------------------------------
三、门控"干净"时的修正逻辑
------------------------------------------------------------------
alpha  = atan2(w_lp.y, w_lp.x)          w_lp = 世界系 10 抽滑动平均
traw   = wrap(-alpha + 磁偏角 + datum常量)
target = wrap(traw - mag_datum_offset)
yaw_P  = clamp(yaw_P + 3e-6*dt, 0, 0.05)
innov  = wrap(target - yaw_corr)
R      = max(4e-6, (sigma_lp/horiz)^2) / w
K      = yaw_P / (yaw_P + R)            （小角度，秒级慢速牵引）
|innov|>20 度 或 NIS>9 -> 大修正路径：slew 92~183 deg/s（无冻结）
输出   q_out = q_z(yaw_corr) * q_gamerv   （纯竖直轴旋转，roll/pitch 不受影响）

------------------------------------------------------------------
四、运行时命令（CDC，单字符 + T 文本行）
------------------------------------------------------------------
单字符：H 标定开始 / J 结算 / K 清除 / R 丢锁 / G 恢复保存的标定 /
        P 打印磁状态表 / L 列传感器 / S 传感器信息 / W 开学习窗 / X 锁学习
T 文本行（以 \n 结尾）：
        T DIR <0..100>   设置方向门静止强度（上限 95）
        回执 TUNE dir_strength=<pct> dir_thr_d100=<x100度> dir_emax_x100=<e*100>

六、已知限制（有意保留）
------------------------------------------------------------------
1. Final output guard 只查 6 个物理门：方向门锁定期间仍会把 weight 擦回 100%、
   status 写成 LOCKED -> 面板显示"已生效"而实际修正被跳过。
2. 静止时方向门常被磁力计方向噪声（相邻样本夹角 P95=3.9 度、P99=7.7 度、
   最大 10.6 度）误触发（>门限 4.7 度 占 29%），dir_lock 被反复续期，
   静止时修正基本冻结 —— 这是"静止强抗磁"的代价。
3. 运动时方向门强度降到 20%（门限 16.6 度），此期间靠近的磁铁不会被该门拦住。
