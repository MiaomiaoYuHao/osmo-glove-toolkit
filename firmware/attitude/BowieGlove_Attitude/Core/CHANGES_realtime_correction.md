# 运动中实时修正

改动文件：`Inc/glove/mag_fusion.h`、`Src/glove/mag_fusion.c`、`Src/glove/bhi360.c`，新增 `tests/`。

## 问题

剧烈运动时一度都不修正，停下后才回正，并且肉眼可见。仿真复现：900 deg/s 甩动，停止瞬间误差 20.4 度，
等于六轴累积误差全部；停后约 6 秒回正。四个原因叠加：

1. yaw 滤波器过程噪声只随时间增长，P 停在静止值（约 0.1 度），运动中任何亚度级分歧都被 NIS 判为离群，
   送进"大新息 + 0.5 s hold"慢路径。
2. mag 样本与"当前"四元数配对，没有时间对齐；`[1 2 1]/4` 预滤波本身还有一个样本（10 ms）群延迟。
   世界系向量在每个甩动折返点都会跳，`e_step` 尖峰，hold 反复清零，运动中永远不修正。
3. 方向检测器归一化错误：除以 |m_prev|^2 而非 |u1|*|expected|。模长 0.3% 的噪声读成 4.4 度方向变化，
   静止时噪声即可触发硬事件，恢复旧快照，撤销已完成的修正。
4. 错拍污染 gate 4 锚点，停下后 e_drift 误报，weight 被压在 0.2 数秒。

另有一个原有抗磁漏洞：`geo_q` 对每个样本学习。强磁铁下 |u| = 1.28，geo_q 被推高，它驱动的 pad
放宽所有门，磁铁仍在时门就解除了。

## 改动

- **时间戳对齐**：新增 `mag_fusion_on_mag_ts()`。8 深度四元数历史，按样本自己的采样时刻插值姿态，
  并解析补偿 FIR 群延迟 `(MAG_BODY_FIR-1)/2` 个样本周期（周期由时间戳实测）。
  持续过新的时间戳流不会再被无限延后（旧逻辑会让整条磁力计路径失效）。
- **在线延迟估计**：从未滤波样本、用自带的原始样本参考做梯度估计，只在旋转不变门（模长/倾角/梯度）
  干净时学习，并拒绝不可能由时间误差产生的残差（垂直于运动方向、或隐含时间误差超出物理范围）。
  ±20 ms 两个方向都能收敛，无偏差；强磁铁之后偏离不超过约 1.4 ms，并随后续运动自愈。
- **随转动增长的协方差** `MAG_YAW_SF`：相关误差模型 (sf*Theta)^2，被接受的更新重置 Theta。
  静止时不起作用。测量方差加时间抖动项 `(MAG_YAW_TJIT_S*omega)^2`。
- 修正方向检测器归一化，其阈值加时间抖动项。
- `geo_q` 只从干净样本学习。
- `bhi360.c` 改调 `mag_fusion_on_mag_ts()`；`MAG_DIAG_PRINT` 行尾新增 `TSOFF`（1/100 ms）。

## 上机

1. 打开 `MAG_DIAG_PRINT`，第一次剧烈甩动几秒后看 `TSOFF` 收敛到多少。它是硬件常数，
   可以写进 `MAG_TS_OFFSET_S` 作初值，之后开机就不必再学。
2. 如果 `TSOFF` 贴到 ±2500（即 ±25 ms 上限），说明实际延迟超出范围，把 `MAG_TS_OFFSET_MAX_S` 调大，
   并把结果告诉我。
3. 双磁力计（mag2）尚未做时间对齐；运动中 `e_grad` 若频繁误报，这是下一处要做的。
