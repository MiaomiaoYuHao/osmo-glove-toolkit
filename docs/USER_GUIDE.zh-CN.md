# OSMO Magnet 3D Force 使用说明

## 1. 安装

要求：

- Windows 10/11
- Python 3.12 推荐
- Bowie USB CDC 设备 `2833:B015`

安装依赖：

```powershell
python -m pip install -r requirements.txt
```

启动：

```powershell
python "host\3D力测试上位机.pyw"
```

也可以双击项目根目录的：

```text
run_3d_force.bat
```

## 2. 基本接线与启动

1. 给 STM32/Bowie 板供电并连接 USB。
2. 确认设备管理器中出现 USB 串行设备。
3. 启动上位机，选择 `COMx` 后点击“连接”。
4. 把磁皮放在静止状态，按 `Z` 或点击“双磁零点”。
5. 零点采集期间不要触碰磁皮。

## 3. 三维力显示

窗口包括：

- 顶部 `Fx/Fy/Fz/|F|` 数值
- XY、XZ、YZ 三个网格平面
- 矢量在三个平面的投影点
- 主三维矢量
- 下方 `Fx/Fy/Fz` 三轴曲线

快捷键：

- `Z`：双磁零点
- `R`：复位显示量程
- `I`：软硬铁标定
- `D`：演示模式
- 六方向标定使用界面按钮

## 4. 软硬铁标定

目的：补偿磁皮姿态变化、安装偏差和环境硬铁/软铁影响。

操作：

1. 点击“软硬铁标定(I)”或按 `I`。
2. 在采集期间缓慢旋转传感器，覆盖 X/Y/Z 三个方向。
3. 采集完成后，软件分别拟合两路磁力计。
4. 结果保存在 `force_iron_calibration.json`。

如果拟合失败，增加旋转角度和采样时间，不要只在一个平面内旋转。

## 5. 六方向揉搓标定

目的：把实际差分磁场主轴映射成物理 X/Y/Z 方向。

操作：

1. 点击“六方向标定”。
2. 按提示依次完成 +X、-X、+Y、-Y、+Z、-Z。
3. 每个方向先明显移动一次，然后在该方向反复揉搓。
4. 软件使用 PCA 提取主轴，并根据第一次运动确定正负方向。
5. 六个方向完成后，矩阵保存到 `force_direction_calibration.json`。

如果方向不正确：

1. 点击“清除六方向标定”。
2. 重新采集。
3. 每个方向都要有足够的来回运动，不要只点一下。

## 6. 固件稳定性修复

本次固件补丁主要解决：

- 强磁突变触发未知 BHI360 事件后 FIFO 解析零步进死循环
- FIFO 读取返回 0 字节时无限空转
- 解析错误被后续成功值覆盖，无法触发恢复
- BHI360 `SENSOR_ERROR`、`FIFO_OVERFLOW`、`RESET` 后不重初始化
- 重初始化失败后永久跳过该路传感器
- USB CDC 半帧写入
- I2C 连续错误恢复
- 主循环和 USB 服务互相阻塞

## 7. 故障排查

### 看不到串口

- 确认设备管理器有 `2833:B015`
- 换 USB 线和 USB 口
- 关闭其他占用 COM 口的程序

### 有串口但 frames 不增长

- 先用纯数据读取脚本确认固件是否输出
- 检查是否运行的是带强磁恢复补丁的 HEX/BIN
- 把磁铁移远后等待重初始化
- 如仍不恢复，通过 ST-Link 复位板子

### 没有曲线

- 确认已经收到真实磁数据
- 确认零点已经完成
- 检查“连接”状态是否为已连接

### 强磁测试后界面恢复但数值异常

- 移开强磁
- 重新按 `Z` 建立零点
- 必要时重新做软硬铁或六方向标定
