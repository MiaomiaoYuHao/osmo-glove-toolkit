# Host development and experiment files

These files are retained for debugging, regression analysis, and replay-engine
development. They are not required to run the main applications.

- ekf_replay_engine.c - experimental native EKF replay engine
- mag_ekf_orig_tmp.c - original EKF reference source
- debug_fit.py / debug_fit2.py - calibration-fit debugging
- test_app_fit.py - application-side fit check
- test_rub.py / test_rub_dbg.py - rubbing-calibration tests
